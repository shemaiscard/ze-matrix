Ze Matrix - Advanced Matrix Operations
=========================================

Overview
-----------
Ze Matrix is a user-friendly tool for learning and performing advanced matrix operations. Built with Streamlit, it offers interactive features for matrix operations, explanations, and quizzes to enhance understanding.
![look](https://github.com/user-attachments/assets/a3730b49-dd6e-4434-b5d4-de4e81449abb)

Features
------------
1. Matrix Operations
   Perform these operations:
   - Addition, Subtraction, Multiplication, Transpose
   - Determinant, Inverse, Scalar Multiplication
   - Power, Rank, Trace, Diagonal
   - Eigenvalues & Eigenvectors, Norm
   - Singular Value Decomposition (SVD), Cholesky Decomposition
   - QR Decomposition, LU Decomposition

2. Educational Mode
   - Detailed concept explanations and visual aids.
   - Interactive quizzes to test knowledge.

3. Linear Equation Solver
   Solve equations of the form Ax = b.

4. Customizable Input
   Input matrices of up to 4x4 size for analysis.

5. Dark Mode
   Supports dark mode for better visibility in low-light conditions.

Installation
--------------
1. Clone the repository:
   ```bash
   git clone https://github.com/shemaiscard/ze-matrix.git
   cd ze-matrix
   ```

2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

3. Run the app:
   ```bash
   streamlit run app.py
   ```

4. Open your browser and go to http://localhost:8501.
   or you can visit hhtps://ze-matrix.streamlit.app 

Usage
----------
1. Matrix Input
   Select the matrix size and input values.

2. Select Operation
   Choose the desired matrix operation from the menu.

3. Educational Mode
   Access explanations and quizzes via the sidebar.

4. Linear Equation Solver
   Provide matrix A and vector b to solve equations.
